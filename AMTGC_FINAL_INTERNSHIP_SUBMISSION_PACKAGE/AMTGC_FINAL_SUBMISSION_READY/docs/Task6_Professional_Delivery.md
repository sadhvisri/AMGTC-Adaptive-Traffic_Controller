# Task 6 — Professional Documentation and Delivery
## Repository
The project is organized into `rtl/`, `tb/`, `sim/`, `docs/`, `waveforms/`, `diagrams/`, and `verification/`.

## Reproducibility
The preferred ModelSim command is:
`do sim/run_all.do`

## Documentation
The final package contains a complete technical report with architecture, RTL, FSM, verification, debugging, limitations and evidence. Supporting documents include a bug log, assumptions document, coverage matrix and self-attestation checklist.

## Evidence
Waveform and transcript screenshots are archived with meaningful filenames.

## Final engineering rule
The delivered RTL must match the version used for the passing verification run.
